MICRO INTERACTION

Masaüstü Mouse Parallax Tilt Mekaniği

Masaüstünde mouse hareket ettirildiğinde ürün kutusu ve arka plan ışığı zıt yönlerde mikro hareket eder:

// Parallax Tilt Formülü (Masaüstü Özel)
productBox.style.transform = `translate3d(${x * 8}px, ${y * 8}px, 0) rotateX(${-y * 4}deg) rotateY(${x * 4}deg)`;
bgGlow.style.transform = `translate(calc(-50% + ${x * 15}px), calc(-50% + ${y * 15}px))`;
✓ Mobilde pil ve performans için otomatik kapalıdır.
✓ prefers-reduced-motion durumunda sıfırlanır.
