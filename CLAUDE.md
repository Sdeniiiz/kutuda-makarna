## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## UI/UX Pro Max & 21st.dev Design Standards

This project follows the **UI/UX Pro Max 10,000$ Agency Standard** (inspired by 21st.dev and Framer Motion):

- **No Generic AI Slop:** Always use authentic food photography, warm cream/stone backgrounds (`#FBF9F5`, `#F4EFEA`), charcoal typography (`#1C1917`), and amber accents (`#FFB800`, `#D97706`).
- **Spring Motion:** Use smooth spring curves (`cubic-bezier(0.16, 1, 0.3, 1)` or `motion`) for hover lifts, button presses, and page transitions.
- **21st.dev Components:** Use Bento Grids, Social Proof / Verified Testimonials, Shimmer CTA Buttons, and Floating Live Status Pills.
- **Franchise Engine:** Keep all code modular under the Website Engine architecture. Never duplicate frontends per branch.
